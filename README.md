# 印象·派对 · 上博东馆印象派特展线上展厅

基于上海博物馆东馆「印象·派对：POLA 美术馆藏近现代绘画特展」现场图文资料制作的静态线上展厅。

## 内容

- 6 个单元：破冰游戏、舞池中央、烟火辉映、霓虹照夜、复调回响、余兴派对
- 61 组展项 / 68 件作品 / 35 位艺术家 / 54 条艺术关系
- 首页拼贴、3D 展墙、详情查看与带水印保存、展品目录、时间轴、艺术家关系图、画家百科、标签百科、观展指南
- 关系图默认隐藏连线，点击画家后高亮其关系与相关人物
- 背景音乐：Don McLean《Vincent》，以 Web Audio 合成钢琴音色
- 补充资料：展厅原版「印象·连结」关系图与「印象·足迹」地图，不计入展品与统计

## 本地运行

直接打开 `index.html` 即可浏览。若要使用“保存带水印大图”，建议通过本地静态服务器打开：

```bash
npx serve .
# 或
python -m http.server
```

## 目录

```text
index.html
assets/
  app.js
  style.css
  data.js
  img/thumb/   # 520px 缩略图
  img/full/    # 1600px 高清图
```

纯静态站点，无后端依赖。
